NUE runtime dependencies on Linux
=================================

Required (every Linux system has them):
  glibc >= the one the package was built on (2.31 for packages built with the Zig toolchain file or on Ubuntu 20.04 / Steam Runtime soldier),
  libm, libdl, libpthread (all part of glibc 2.34+; separate sonames before)
  libstdc++.so.6 / libgcc_s.so.1       unless the package was built with --static-cxx

Optional, loaded with dlopen when present. A missing one disables exactly one feature and the engine logs why:

  Feature                              Library (soname)                         Package names (Debian / Fedora / Arch)
  -----------------------------------  ---------------------------------------  ------------------------------------------------
  Vulkan renderer, GPU probe           libvulkan.so.1                           libvulkan1 / vulkan-loader / vulkan-icd-loader
  GL / GLES fallback                   libEGL.so.1, libGLESv2.so.2, libGL.so.1  libegl1 libgles2 libgl1 / mesa-libEGL ... / libglvnd
  Wayland video                        libwayland-client.so.0, libdecor-0.so.0  libwayland-client0 libdecor-0-0 / ...
  X11 video                            libX11.so.6, libXi.so.6, libXext ...     libx11-6 libxi6 libxext6 / ...
  Audio: PipeWire (preferred)          libpipewire-0.3.so.0                     libpipewire-0.3-0 / pipewire-libs / libpipewire
  Audio: PulseAudio                    libpulse.so.0                            libpulse0 / pulseaudio-libs / libpulse
  Audio: ALSA                          libasound.so.2                           libasound2 / alsa-lib / alsa-lib
  Gamepad hot-plug                     libudev.so.1                             libudev1 / systemd-libs / systemd-libs
  GameMode (performance)               libgamemode.so.0                         libgamemode0 / gamemode / gamemode
  D-Bus services (power profiles,      libdbus-1.so.3                           libdbus-1-3 / dbus-libs / dbus
   idle inhibit, rtkit, logind
   suspend/resume, GameMode fallback)
  Steamworks (optional, your depot)    libsteam_api.so                          ships with the game, never required

Headless / CI: SDL_VIDEODRIVER=dummy and SDL_AUDIODRIVER=dummy need none of the libraries above.

Steam Deck / SteamOS: everything above except GameMode is already installed; install the game under $HOME, not the read-only root.
